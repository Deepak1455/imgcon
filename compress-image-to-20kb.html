Step-by-step: get a photo under 20KB

  1. Read the official upload instructions. Identify whether the limit applies to a photograph, signature, or both. Note the required file type, dimensions or pixel range, and whether the limit is “under” or “up to” 20KB.
  2. Choose a suitable source image. Start with a clear, correctly oriented photo. If the source is much larger than the portal needs, reducing its dimensions can save more data than lowering quality alone. Keep an untouched original so you can start over.
  3. Select the photo in ImgCon. The editor sets the 20KB target for this page. Pick the required image format from the editor when the application specifies one. The tool works in your browser and previews the output as settings change.
  4. Crop and resize only when needed. Match the portal's composition and pixel dimensions; a file-size target cannot correct a wrong crop or guarantee that a face is framed as required. For signatures, preserve legibility and avoid cropping strokes.
  5. Download and verify the actual file. Check the result size and dimensions shown by the editor, and confirm the downloaded filename and extension. If the portal rejects it, re-check whether it expects a different format, exact dimensions, or a stricter size threshold.

Why a 20KB limit needs careful checking

Compressing a high-resolution photograph to a small file means the encoder must discard detail, reduce dimensions, or both. JPEG and WebP can make photographic images smaller, while PNG is often larger for photos and is useful for graphics or transparency. The best setting depends on the source: a plain background compresses differently from a detailed scene. A low byte count is not useful if text, facial details, or a signature becomes unreadable.

Some exam forms specify minimum and maximum dimensions as well as a maximum file size. Satisfying one constraint does not satisfy the others automatically. ImgCon's target is a practical starting point; it cannot interpret the portal's rules, certify identity photos, or guarantee acceptance by SSC, UPSC, or another organization. Inspect the exported image at normal size and compare every requirement before you submit it.

Privacy: image editing happens locally in your browser. The image file is not uploaded to ImgCon's image-processing server. Avoid sending private photos by email when asking for technical support.

Common questions

How do I compress a photo to 20KB for an SSC or UPSC form?

Select a photo in ImgCon, choose the 20KB target, and download the processed image. Check the form's current format and dimension requirements and verify the output file size before uploading. The selected value is a target maximum; the final file may be smaller.

What if my file is still too large?

Try reducing image dimensions while preserving the required aspect and crop, or use a format accepted by the portal that produces a smaller image. Do not keep lowering quality if the subject becomes hard to recognize. The source image and portal requirements may make the requested combination impractical.

Can I use the same result for every application?

Not necessarily. Each form can have its own photo rules. Confirm that the current application accepts the chosen format, size, background and dimensions before uploading.
