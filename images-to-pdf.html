How to combine images into a PDF

  1. Select all document images, or drag them into the upload area.
  2. Arrange the page order, remove any unwanted page, and select page orientation and a quality preset.
  3. Select Merge & Download PDF, then check the PDF size and legibility against the current portal requirements.

Frequently asked questions

Are my documents uploaded while creating a PDF?

No. Image decoding, canvas conversion, and PDF assembly run in your browser. Your documents are not sent to an ImgCon image-processing server.

Can I create one PDF from Aadhaar front and back?

Yes. Select both images, move them into the required order, choose a quality preset, and create the PDF.

Will the PDF always be below 1MB or 500KB?

The compression presets retry at smaller dimensions and lower JPEG quality, but no fixed size can be guaranteed for every selection. The resulting size and any target miss are displayed.

Can I change page order after adding images?

Yes. Use the up/down page controls before merging. Delete removes a page from the queue.
