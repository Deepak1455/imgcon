Step-by-step: crop a portrait to 3.5 × 4.5

  1. Check the destination's photo guide. Read the current instructions for the passport, visa, identity card or form you are completing. Confirm the aspect ratio, accepted file types, pixel size, background, head size and any maximum file size.
  2. Choose a suitable portrait. Start with a clear, front-facing photo that has room around the head and shoulders. The editor can crop and resize an image, but it cannot change the source lighting or make a non-compliant pose suitable.
  3. Apply the 7:9 crop. This page opens ImgCon with the 3.5:4.5 crop preset. Position the crop using the available controls and check that the face remains comfortably inside the required framing.
  4. Set pixel dimensions separately. If the instructions require a particular width and height in pixels, enter those values in the resize controls after cropping. The ratio alone does not specify resolution or print density.
  5. Review, export and verify. Inspect the image at full size, confirm format and file size, then download it. If making a printed photo, check the print dialog or document layout so that it is actually printed at the stated centimetre dimensions.

Crop ratio versus physical print size

For a 3.5 cm wide by 4.5 cm tall photo, the width-to-height ratio is 3.5 divided by 4.5, or approximately 0.778. That is equivalent to 7:9. Cropping to 7:9 means the digital image has the correct shape, but it does not specify how many pixels it contains. A 700 by 900 pixel file and a 1400 by 1800 pixel file share the same ratio while containing different amounts of detail.

Physical print size depends on how those pixels are mapped to paper. Print resolution and the settings in a printer, photo kiosk or document editor affect the result. Likewise, a portal may want a precise pixel range rather than centimetres. Do not infer the authority's pixel or print rules from the ratio. Follow the published photo specification for that exact application.

Important: cropping and compressing cannot validate identity-photo rules such as permitted background, lighting, expression, accessories or face position. ImgCon is a general-purpose editor and does not provide official photo approval.

Frequently asked questions

Is 3.5 × 4.5 cm accepted for every passport?

No. Photo specifications vary by country, document type and application method. The ratio is a convenient crop preset only; check the issuing authority's current directions.

Can the editor resize the file to a specified number of pixels?

Yes. Use the width and height controls in the editor to enter the pixel dimensions required by your destination. Check the resulting dimensions and preserve the crop ratio where required.

Are my photos uploaded?

No image-processing upload is involved. ImgCon uses browser-based image processing, so the selected photo remains on your device while it is edited.
